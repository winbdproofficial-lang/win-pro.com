# WINBD-PRO Production Website
# Gaming Platform with Live Game Integration

This is the production website for WINBD-PRO gaming platform.

## Features
- User authentication (login/register)
- Live game integration (Pragmatic, PGSoft, Amatic, Amusnet)
- Wallet management (deposit/withdraw)
- Payment gateway integration (SSLCommerz)
- Admin dashboard
- Responsive design

## Deployment
Built for Render.com deployment with Supabase PostgreSQL

See `.github/workflows` for CI/CD configuration.
